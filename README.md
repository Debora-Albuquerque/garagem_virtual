# 🚗 Garagem Virtual (Mão na Roda)

> **"O seu assistente automotivo inteligente."**

Sistema web moderno, responsivo e intuitivo desenvolvido para o gerenciamento completo de veículos particulares. Com uma interface limpa em *dark mode* e foco em privacidade (utilizando armazenamento local), o aplicativo ajuda motoristas a controlarem sua garagem, abastecimentos, manutenções, agenda de revisões e contarem com um assistente técnico inteligente integrado.

---

## 🛠️ Tecnologias Utilizadas

* **React** (Biblioteca principal para construção da interface)
* **Tailwind CSS** (Estilização e design responsivo)
* **Lucide React** (Ícones modernos e minimalistas)
* **LocalStorage** (Persistência de dados local, garantindo total privacidade)

---

## ✨ Funcionalidades Principais

1. **Garagem Virtual / Perfil do Veículo:**
   * Cadastro e personalização dos dados do carro (Modelo, Ano, Placa, Quilometragem atual e Data de Aquisição).
   * Painel de lembretes rápidos para documentos e obrigações (IPVA, Licenciamento, Seguro).

2. **Módulo de Abastecimentos:**
   * Registro detalhado de abastecimentos (Data, Posto/Bandeira, Valor pago, Litros, Tipo de combustível e Autonomia).
   * Cálculo automático de consumo médio (km/l).

3. **Histórico de Revisões e Manutenções:**
   * Acompanhamento de serviços realizados, oficinas, quilometragem das trocas e simulação de anexos de notas fiscais/garantias.

4. **Agenda de Próximas Revisões:**
   * Planejamento preventivo baseado em datas ou quilometragem.

5. **Registro de Modificações (Upgrades / Tuning):**
   * Seção dedicada para customizações e termos de garantia.

6. **Assistente Técnico Inteligente:**
   * Consulta rápida por Modelo e Ano com base interna otimizada para veículos populares (incluindo linhas Chevrolet, Toyota, Honda, Hyundai, VW Polo/Nivus/Virtus, Jeep, Fiat e Renault) com fluidos recomendados e dicas preventivas.

## 🚀 Como Executar o Projeto Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Debora-Albuquerque/garagem_virtual.git
   cd garagem_virtual
   ```
2. Instale as dependências:
   ```bash
   npm ci
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Abra no navegador o endereço exibido pelo Vite (por padrão, `http://localhost:3000`).
